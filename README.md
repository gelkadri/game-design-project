# Pink Sky Explorer - Lost in the Sky Realms
2D tilemap platformer Unity project themed around floating sky realms.
Create your own 2D platformer game with ease using this Unity project template. This repository now focuses on a pink-toned "Sky Explorer" adventure across magical sky islands.

## Features:
Tilemap Integration: Leverage Unity's Tilemap system for efficient level design and quick iteration.

Sky Explorer Controller: A customizable explorer controller script with smooth movement and double jump movement.

Animated Player Controller: Player control with Idle, Run, Jump animations implemented in the project.

Game Manager and UI Manager: Systems to manage gameplay.

Player Death and Respawning: Respawn and death system.

Platformer Mechanics: Jumping, double-jumping, and grounded movement are all set up for a classic platformer feel.

Sky Collectibles: Coins and sky crystals to make gameplay feel fun.
